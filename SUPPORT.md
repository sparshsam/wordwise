# Support

WordWise is a reflective word-of-the-day practice app. Support is best-effort and focused on reproducible bugs, content data issues, documentation, and local development.

## Before Opening An Issue

- Check the [README](README.md), [SECURITY.md](SECURITY.md), and [CONTRIBUTING.md](CONTRIBUTING.md).
- Search existing issues and pull requests.
- Include the word, route, or content state involved when reporting data issues.

## Good Issue Reports

- Provide steps to reproduce.
- Include expected and actual behavior.
- Mention whether the issue appears locally, on Vercel, or both.

For security concerns, follow [SECURITY.md](SECURITY.md).
